# 远期迭代增强计划

> Moon Cross v0.4.0 → v1.0.0+ 演进路线图
> 四维增强：易用性 · 鲁棒性 · 安全性 · 性能

## 总览

| 维度 | 当前状态 | 目标状态 | 关键里程碑 |
|------|----------|----------|------------|
| 易用性 | CLI 骨架 + 手动配置 | 零配置 + 交互式 + 自动发现 | v0.6.0 |

## 一、易用性增强（v0.5.0 → v0.6.0）

### 1.1 零配置启动
- **自动发现**：扫描 `moon.mod` 自动推导导出函数列表，无需手写 `moon-cross.json`
- **智能默认**：根据平台可用性自动选择目标平台（检测 NDK/Xcode/OHOS SDK）
- **配置继承**：支持 `moon-cross.json` 继承基础配置，减少重复

### 1.2 交互式 CLI
- **init 向导**：交互式问答生成配置（库名 → 导出函数 → 目标平台 → FFI 选项）
- **build 进度**：实时显示四平台编译进度条 + 耗时统计
- **plan 可视化**：构建计划以树状图展示（config → C code → compile → FFI → package）

### 1.3 错误提示优化
- **错误定位**：配置错误精确到字段名 + 行号
- **修复建议**：常见错误附带修复建议（如 "缺少 NDK 路径，试试设置 ANDROID_NDK_HOME"）
- **诊断命令**：`moon-cross doctor` 自动检测环境问题

### 1.4 文档与示例
- **自动文档**：从导出函数签名自动生成 API 文档
- **示例库**：提供 5+ 跨平台示例（zlib/base64/json/hash/regex）
- **交互式教程**：`moon-cross tutorial` 引导新手完成首个跨平台项目

## 二、鲁棒性增强（v0.6.0 → v0.7.0）

### 2.1 错误恢复机制
- **编译失败恢复**：单平台失败不阻塞其他平台，汇总报告所有失败
- **FFI 绑定回退**：FFI 生成失败时回退到纯 C 绑定 + 手动 FFI 模式
- **配置降级**：缺少可选配置时使用安全默认值而非报错

### 2.2 重试策略
- **编译重试**：交叉编译失败自动重试（调整优化级别/链接选项）
- **网络重试**：mooncakes 依赖下载支持指数退避重试
- **超时控制**：每个平台编译设置独立超时，避免卡死

### 2.3 配置校验增强
- **Schema 校验**：JSON Schema 严格校验 `moon-cross.json` 格式
- **语义校验**：检查函数签名合法性（参数类型/返回值/命名冲突）
- **平台兼容性**：检查导出函数在目标平台的兼容性（如 UInt 在某些平台不支持）

### 2.4 边界条件处理
- **空输入**：空函数列表/空平台列表/空配置文件的优雅处理
- **超大输入**：大型库（100+ 导出函数）的内存控制 + 分文件生成
- **特殊字符**：模块名/函数名含 Unicode/空格/保留字的处理

## 三、安全性增强（v0.7.0 → v0.8.0）

### 3.1 内存安全
- **ASAN 验证**：C wrapper 代码生成后自动用 AddressSanitizer 验证内存安全
- **引用计数审计**：自动插入引用计数检查点，检测泄漏
- **缓冲区边界**：生成的 C 代码自动插入数组边界检查

### 3.2 FFI 边界安全
- **输入校验注入**：FFI 绑定自动生成参数校验代码（null 检查/长度检查/类型检查）
- **输出封装**：FFI 返回值自动封装为安全类型（避免裸指针暴露）
- **调用隔离**：FFI 调用异常不传播到宿主语言，自动转换为错误码

### 3.3 沙箱隔离
- **编译沙箱**：交叉编译在临时目录中执行，不污染源码树
- **输出隔离**：各平台输出目录隔离，避免文件覆盖
- **权限最小化**：生成的 FFI 绑定只声明最小必要权限

### 3.4 供应链安全
- **依赖锁定**：moon-cross.json 支持依赖版本锁定（类似 lock 文件）
- **校验和验证**：下载的 mooncakes 依赖自动验证 SHA-256 校验和
- **许可证兼容性**：自动检查依赖许可证与目标项目的兼容性

## 四、性能提升（v0.8.0 → v0.9.0）

### 4.1 并行编译
- **四平台并行**：iOS/Android/Windows/鸿蒙编译并行执行（4x 加速）
- **多架构并行**：同一平台多架构（arm64/x86_64）并行编译
- **任务调度**：基于 CPU 核数自动调度并行度

### 4.2 缓存机制
- **编译缓存**：基于源码哈希的增量编译缓存，未修改的文件跳过编译
- **代码生成缓存**：C wrapper/FFI 绑定生成结果缓存，配置未变时复用
- **依赖缓存**：mooncakes 依赖本地缓存，避免重复下载

### 4.3 增量构建
- **变更检测**：`moon-cross sync` 只重新生成变更函数的 C wrapper + FFI 绑定
- **差异输出**：只输出变更文件，支持 git diff 集成
- **预热**：`moon-cross warmup` 预编译常用配置

### 4.4 代码生成优化
- **模板特化**：根据函数签名生成特化代码，避免通用模板的开销
- **内联优化**：小型 wrapper 函数自动内联
- **死代码消除**：自动检测并消除未使用的 FFI 绑定代码
